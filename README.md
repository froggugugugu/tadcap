# Tadcap

<img src="docs/media/icon.png" alt="" width="64" height="64" align="right" />

撮る → 描き込む → 貼る を最短で。macOS 専用の、キャプチャを主役にした軽量なスクリーンショット注釈ツールです。
番号スタンプ・スポットライト・トリミングで、職場の説明や手順書に使う「伝わる 1 枚」をすぐに作れます。処理は Mac の中だけで、撮った画像をディスクに残しません。

> tadpole（オタマジャクシ）+ capture

- 紹介ページ: <https://froggugugugu.github.io/tadcap/>
- 動作環境: macOS 14（Sonoma）以降

![Tadcap のエディタ。架空の設定画面のキャプチャに、①②③ の番号スタンプ・矢印・スポットライトで手順を描き込んだところ](docs/media/editor.png)

## できること

- **どこからでもキャプチャ**: `⌘⇧2`(設定で変更可)で範囲選択を開始（macOS 標準の `screencapture -i` を使用）。範囲選択中にスペースキーでウィンドウ選択に切り替え
- **描き込み**: テーパー矢印・矩形・円・テキスト（小・中・大）・スタンプ・モザイク・スポットライト・トリミング
- **スタンプ**: 番号 ①②③ はクリックするたびに 1 つずつ増え、途中を消すと詰め直す。記号は ✓ × ! ? の 4 種類(`N`)。手順の説明や、不具合の再現手順に
- **スポットライト**: 囲んだ所以外を暗くして「ここを見て」を一目で伝える。囲みはいくつでも置け、あとから移動・リサイズできる(`S`)
- **トリミング**: 撮った後から残す範囲だけに切り抜く。描いた注釈も一緒に動き、`⌘Z` で切る前に戻せる(`C`)。となりの窓や通知など、余計な情報を写さずに済む
- **縮めてコピー**: 設定画面の「コピーを等倍に縮める」をオンにすると、高精細な画面で撮った画像を画面で見えていた大きさに縮めてコピーする(倍率 2 倍の画面なら縦横 1/2)。チャットや資料に貼ったとき大きすぎない。既定はオフ
- **ツールはキー 1 つで切り替え**: `A` 矢印・`R` 矩形・`O` 円・`T` テキスト・`N` スタンプ・`M` モザイク・`S` スポットライト・`C` トリミング([一覧](#ツールの切り替えキー-1-つ))
- **描いた後も調整できる**: 矢印・矩形・円・テキスト・スタンプ・スポットライトはクリックで選び直して移動、ハンドルでリサイズ(テキストはダブルクリックで打ち直し)。選択中は色・文字サイズの変更、`Delete` で削除、`⌘⇧F` / `⌘⇧B` で最前面・最背面へ。`Shift` で正方形・正円。1 枚の画像に 50 個まで(超えると古いものから画像に固定)。履歴を切り替えて戻っても続きから調整できる
- **色**: 6 色のプリセット（ピンク・赤・橙・黄・緑・青）とカラーピッカー（モザイク・スポットライト・トリミング以外に適用）
- **取り消し・やり直し**: `⌘Z` / `⌘⇧Z`(トリミングも 1 回で切る前に戻せる)
- **機密らしい箇所を探す(自動マスキング)**: `⌘⇧M` かツールバーのボタンで、画像の中の機密らしい箇所(連絡先・認証情報・識別子・金額や口座)に色付きの印を付けます。モザイクをかけたくない印はクリックで外し、「まとめてモザイク」で残りに一度にモザイクをかけます。`⌘Z` 1 回で全部戻せます。詳しくは[自動マスキング](#自動マスキング機密らしい箇所を探す)
- **クリップボードへコピー**: `⌘C` で描き込んだ画像をコピーし、そのまま他のアプリへ貼り付け
- **セッション内の履歴**: 起動中に撮った画像をサムネイルで一覧し、描き込んだ状態で呼び戻せる
- **メニューバー常駐**: メニューから「キャプチャ」「エディタを開く」「終了」。Dock にも表示し、アイコンを押すとエディタが開く
- **何も残さない**: 画像はディスクに保存しない。履歴はメモリのみで終了時に破棄、一時ファイルは起動時・終了時に自動削除。外部との通信なし

## インストール

配布版は Apple silicon の Mac（macOS 14 以降）向けです。Intel の Mac では[ソースからビルド](#ソースからビルド)してください。

### コマンドで入れる（おすすめ）

```bash
curl -fsSL https://froggugugugu.github.io/tadcap/install.sh | bash
```

最新版を [Releases](https://github.com/froggugugugu/tadcap/releases) から取得し、公開時のチェックサム（sha256）と照合してから「アプリケーション」フォルダ（書き込めなければ `~/Applications`）に入れて起動します。更新も同じコマンドで、起動中の Tadcap は終了してから置き換えます。

環境変数で動きを変えられます（例: `curl -fsSL ... | TADCAP_NO_OPEN=1 bash`）。

| 変数 | 意味 |
| ---- | ---- |
| `TADCAP_VERSION=0.1.0` | 最新版の代わりにこの版を入れる |
| `TADCAP_APP_DIR=DIR` | `DIR` に入れる |
| `TADCAP_ZIP=FILE` | ダウンロード済みの `Tadcap-<版>-arm64.zip` から入れる |
| `TADCAP_NO_OPEN=1` | 入れたあと起動しない |

### DMG をダウンロードする

1. [最新のリリース](https://github.com/froggugugugu/tadcap/releases/latest)から `Tadcap-<版>-arm64.dmg` をダウンロードして開き、`Tadcap.app` を「アプリケーション」フォルダへドラッグします
2. 起動します。初回に「インターネットからダウンロードされたアプリケーションです。開いてもよろしいですか?」と出たら「開く」を押します

配布物は Developer ID で署名し、Apple の公証を受けています（v0.4.0 以降）。

### ソースからビルド

必要なもの:

- macOS 14 以降
- Xcode Command Line Tools（`xcode-select --install`）
- Rust（stable。[rustup](https://rustup.rs/) で導入）
- Node.js 20 以降と npm

```bash
git clone https://github.com/froggugugugu/tadcap.git && cd tadcap
npm install
npm run tauri build -- --bundles app
```

できあがった `src-tauri/target/release/bundle/macos/Tadcap.app` を「アプリケーション」フォルダへ移します。

## 初回セットアップ（画面収録の許可）

画面を撮るには macOS の「画面収録」の許可が必要です。

1. 許可がないままキャプチャしようとすると、Tadcap は範囲選択を始めずに案内を表示します
2. 「システム設定を開く」を押し、「プライバシーとセキュリティ」→「画面収録」で Tadcap をオンにします
3. 反映されないときは、メニューバーのアイコンから「終了」を選び、Tadcap を起動し直してください

![画面収録の許可がないときに表示される案内](docs/media/permission.png)

## 使い方

1. `⌘⇧2` を押して範囲をドラッグ（スペースキーでウィンドウ選択、`Esc` で中止）
2. 開いたエディタで、ツールバーかキー 1 つ(`A` `R` `O` `T` `N` `M` `S` `C`)でツールを選び、色（テキストとスタンプは大きさも）を選ぶ
3. 画像の上をドラッグして描く。スタンプはクリックした所に置かれ、番号は置くたびに増える。テキストはクリックした位置に入力して `Enter`。描いたものはクリックで選び直して調整できる
4. 必要ならトリミング: `C` で残す範囲をドラッグし、枠やハンドルで調整して `return`(または「確定」)。`esc` でやめる
5. `⌘C` でクリップボードにコピーし、貼り付けたい場所で `⌘V`

![ツールバー。キャプチャ、矢印・矩形・円・テキスト・スタンプ、モザイク・スポットライト・トリミング、色、文字サイズ、最前面へ・最背面へ、取り消し・やり直し、機密らしい箇所を探す、クリップボードにコピー](docs/media/toolbar.png)

### 手順を 1 枚で伝える(使用例)

設定の手順書や不具合の再現手順を、文章を長く書かずに画像 1 枚で伝える例です。

1. 番号スタンプ(`N`)で、押す順番に ①②③ を置く。必要なら矢印(`A`)を足す
2. スポットライト(`S`)で、見てほしい所だけを明るく残す
3. トリミング(`C`)で、メニューバーやとなりの窓など余計な所を切り落とす
4. `⌘C` でコピーして貼る

![トリミング中のエディタ。帯に「残す範囲 1280 × 800」と「やめる」「確定」。架空のデスクトップのキャプチャで、設定の窓だけが枠とハンドルで囲まれ、メニューバーとメモの窓は暗くなっている](docs/media/crop.png)

![貼り付けられる画像。架空の設定の窓だけが残り、①アカウント・②二段階認証のトグル(矢印付き)・③保存ボタンの 3 か所が明るく、ほかは暗くなっている](docs/media/steps.png)

*写っている画面・文字はすべて架空のものです。*

### 縮めてコピー

高精細な画面で撮った画像は、画面で見えていた大きさの縦横 2 倍などになり、チャットや資料に貼ると大きく見えます。メニューバーのアイコンかアプリメニューの「設定…」(`⌘,`)で「コピーを等倍に縮める」をオンにすると、見えていた大きさに縮めてコピーします。切り替えるとすぐに保存され、既定はオフです。エディタで編集中の画像は縮めません。

![設定画面。キャプチャのショートカットの下に、チェックの入った「コピーを等倍に縮める」と説明](docs/media/shrink-copy.png)

### 自動マスキング(機密らしい箇所を探す)

貼る前の見直しを手伝う機能です。見つけた箇所は候補(目安)であり、機密をすべて見つけるものではありません。貼る前に、画像を必ず目で確かめてください。

1. 画像を開いた状態で `⌘⇧M`(またはツールバーの取り消しとコピーの間のボタン)を押す
2. 機密らしい箇所に、種類ごとの色の印(連絡先・認証情報・識別子・金額・口座)が付く
3. モザイクをかけたくない印はクリックで外す(もう一度クリックで戻す)。`Esc` か「やめる」で印を消す
4. 「まとめてモザイク」で、残った印の範囲に一度にモザイクをかける。`⌘Z` 1 回で全部戻せる

文字の読み取りと判定は Mac の中だけで行い、外部と通信しません。読み取った文字は画面・ファイル・ログのどこにも残しません(印の位置と種類だけを使います)。印は画面に重ねて表示するだけなので、印を出したまま `⌘C` でコピーしても印は写りません。

**拾いやすいもの**: よくある書式のメールアドレス・電話番号・URL の `?` 以降・接頭辞の付いたトークン・長いランダムな英数字の列・カード番号・「パスワード」などのラベルの後の値・通貨記号の付いた金額

**見逃しやすいもの**: 人名(とくに敬称やラベルの無い名前・欧米系の名前)・会社名・住所・珍しい書式の金額や口座番号・画面に「番号」などの手がかりが無い番号・小さい文字や読み取りにくい文字。人名の候補はとくに目安として扱ってください

![自動マスキングの印。架空の請求書画面の会社名・担当者名・住所・メールアドレス・電話番号・金額・カード番号・口座番号・URL のクエリ・照会キーなどに、種類ごとに色の違う枠とラベルが付いている。外した 1 件(請求元の会社名)は破線で薄く表示される。顧客番号には印が付いていない(見逃し)。上の帯に候補の件数と「やめる」「まとめてモザイク」](docs/media/auto-mask.png)

*評価用の架空の請求書(名前・番号などはすべて架空)を実際に読み取った結果です。この例では「顧客番号」の値を見逃しています。*

### ツールの切り替え(キー 1 つ)

| キー | ツール |
| ---- | ------ |
| `A` | 矢印 |
| `R` | 矩形 |
| `O` | 円 |
| `T` | テキスト |
| `N` | スタンプ(番号・✓・×・!・?) |
| `M` | モザイク |
| `S` | スポットライト |
| `C` | トリミング |

- 選んでいるツールのキーをもう一度押すと、ツールの選択が外れます
- 文字の入力中・設定画面を開いている間・自動マスキングの確認中は効きません

### トリミング中

| キー | 操作 |
| ---- | ---- |
| `return` | 確定(切り抜く) |
| `esc` | やめる |
| `⌘Z` | 範囲の指定をやめる(確定した後は、切り抜く前に戻す) |

### ショートカット

| キー | 動作 | 使える場面 |
| ---- | ---- | ---------- |
| `⌘⇧2` | キャプチャを始める(「設定…」で変更可) | どのアプリを使っていても |
| `Space` | 範囲選択とウィンドウ選択を切り替える | 範囲選択中 |
| `⌘C` | 描き込んだ画像をクリップボードにコピー | エディタ |
| `⌘⇧M` | 機密らしい箇所を探す(自動マスキング) | エディタ(画像があるとき) |
| `⌘Z` | 取り消し | エディタ（テキスト入力中は入力欄の取り消し） |
| `⌘⇧Z` | やり直し | エディタ（テキスト入力中は入力欄のやり直し） |
| `Enter` / `Esc` | 選択を外す(テキスト入力中は `Enter` で確定、`Esc` で取り消し) | エディタ |
| `Delete` / `⌫` | 選択中のオブジェクトを削除 | オブジェクト選択中 |
| `⌘⇧F` / `⌘⇧B` | 選択中のオブジェクトを最前面 / 最背面へ | オブジェクト選択中 |
| `⌘,` | 設定画面を開く(ショートカットの変更・縮めてコピー) | Tadcap が前面のとき |
| ダブルクリック | テキストを打ち直す | テキストの上 |
| `Shift`＋ドラッグ | 正方形・正円にする | 矩形・円を描く／大きさを変えるとき |

## よくある質問

**撮った画像が真っ黒、または壁紙しか写らない**
画面収録が許可されていません。[初回セットアップ](#初回セットアップ画面収録の許可)の手順で許可し、必要なら再起動してください。

**更新したら撮れなくなった**
v0.3.x 以前（公証前のアドホック署名の版）から v0.4.0 以降へ更新した直後は、署名が変わったため macOS が別のアプリとみなし、画面収録の許可が外れることがあります。「システム設定」→「プライバシーとセキュリティ」→「画面収録」で Tadcap を一度オフにしてオンにし直すか、一覧から削除して追加し直し、Tadcap を起動し直してください。v0.4.0 以降どうしの更新では、通常は外れません。

**`⌘⇧2` を押しても何も起きない**
ほかのアプリが同じショートカットを使っている可能性があります。メニューバーのアイコンかアプリメニューの「設定…」(`⌘,`)で別のキーに変えるか、メニューバーのアイコンから「キャプチャ」を選んでください。

**貼り付けた画像が大きすぎる**
高精細な画面で撮ると、画像は見えていた大きさの縦横 2 倍などになります。「設定…」(`⌘,`)で「コピーを等倍に縮める」をオンにしてください。[縮めてコピー](#縮めてコピー)

**トリミングで切りすぎた**
`⌘Z` 1 回で、切る前の画像と注釈の位置に戻ります。確定する前なら `esc` で範囲の指定をやめられます。

**撮った画像はどこに保存される？**
保存しません。履歴は起動中のメモリだけに持ち、終了すると消えます。撮影時の一時ファイルは起動時と終了時に自動で削除します。

**自動マスキングで印が付かなかったところは、見せても大丈夫？**
そうとは限りません。印は規則に当てはまった箇所の目安で、人名・住所・珍しい書式の番号などは見逃すことがあります。貼る前に画像を目で確かめ、必要ならモザイクツールで追加してください。

**終了するには？**
`⌘Q`、Dock のアイコンの「終了」、またはメニューバーのアイコンから「終了」を選びます。エディタのウィンドウを閉じても常駐は続き、Dock のアイコンを押すと再び開きます。

## 開発

```bash
npm install
npm run tauri dev     # 開発起動
npm run build         # フロントエンドの型チェックとビルド
npm run test:run      # ユニットテスト(Vitest)
npm run e2e           # E2E テスト(Playwright。Tauri IPC はモック)
npm run dist:mac      # 配布物(release/Tadcap-<版>-arm64.dmg / .zip)を作る
```

リリースの手順: `package.json`・`src-tauri/tauri.conf.json`・`src-tauri/Cargo.toml` の `version` を揃えて上げ、`cargo check --manifest-path src-tauri/Cargo.toml` で `Cargo.lock` も更新してからコミットして push したあと、`git tag v<版>` → `git push origin v<版>` します。タグの push で `.github/workflows/release.yml` が動き、テスト・ビルド・署名の検証を通った DMG と zip を GitHub Releases に公開します。タグと 3 ファイルの版が食い違うと失敗します。

| ディレクトリ | 内容 |
| ------------ | ---- |
| `src/` | フロントエンド(TypeScript + Vite、フレームワークなし): エディタ UI・Canvas 描画・履歴 |
| `src-tauri/` | バックエンド(Rust + Tauri v2): キャプチャ・グローバルショートカット・メニューバー・クリップボード・自動マスキングの文字の読み取りと判定(`src-tauri/src/masking/`) |
| `eval/masking/` | 自動マスキングの評価用の架空画面と正解(`npm run mask:fixtures` で作り直す) |
| `e2e/` | Playwright の E2E テスト(`e2e/screenshots/` は画像撮影用) |
| `docs/media/` | README と紹介ページで使う画像 |
| `.github/pages/` | 紹介ページ(GitHub Pages) |
| `scripts/` | 配布物の作成(`package-mac.sh`)・インストーラー(`install.sh`) |

紹介ページと README の画像は `npx playwright test --config=e2e/screenshots/playwright.config.ts landing` で撮り直せます（写っている画面は架空のものです）。
