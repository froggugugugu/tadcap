# 整合性監査 詳細チェックリスト

## A. スペーシング

- [ ] ボタン内の上下padding が統一されている
- [ ] ボタン内の左右padding が統一されている
- [ ] ボタン間の間隔（隣接する場合）が統一されている
- [ ] 入力フォームの上下余白が統一されている
- [ ] カード・パネル内の内側余白が統一されている
- [ ] カード・パネル間の外側余白が統一されている
- [ ] リストアイテム間の間隔が統一されている
- [ ] モーダル・ダイアログの内側余白が統一されている
- [ ] 画面端（左右）のマージンが全画面で統一されている
- [ ] 全余白値が 8px グリッド（またはトークン値）に沿っている

## B. タイポグラフィ

- [ ] 画面タイトルのフォントサイズが全画面で同じ
- [ ] セクション見出しのフォントサイズが全画面で同じ
- [ ] 本文のフォントサイズが全画面で同じ
- [ ] 補足・キャプションテキストが統一されている
- [ ] フォントウェイトの役割（bold/regular/light）が一貫している
- [ ] 行間（line-height）が役割ごとに統一されている
- [ ] フォントファミリーが意図せず混在していない

## C. コンポーネントサイズ・形状

- [ ] プライマリボタンの高さが全画面で統一されている
- [ ] セカンダリボタンの高さが全画面で統一されている
- [ ] 同じ役割のボタンが異なるサイズになっていない
- [ ] テキスト入力欄の高さがボタンと統一されている
- [ ] ドロップダウンの高さが入力欄と統一されている
- [ ] アイコンサイズが役割ごとに統一されている（sm/md/lg）
- [ ] border-radius が役割ごとに統一されている
- [ ] チェックボックス・ラジオボタンのサイズが統一されている

## D. タイトル・見出し位置

- [ ] 画面タイトルの「上余白（画面端 or ヘッダーから）」が全画面で統一
- [ ] 画面タイトルの「下余白（コンテンツまでの距離）」が統一
- [ ] 画面タイトルの水平位置（左揃え/中央/右揃え）が統一
- [ ] セクション見出しの前後余白が統一
- [ ] タイトルが複数行になるときの行間が考慮されている
- [ ] ページ内ナビゲーション（タブ等）があるときのタイトル位置との関係が統一

## E. カラー

- [ ] テキストカラーが役割別（primary/secondary/disabled/error/link）で統一
- [ ] 背景色がトークン（surface/background/overlay等）に沿っている
- [ ] ボーダー色がトークンに沿っている
- [ ] エラー・警告・成功・情報の色が統一されている
- [ ] ホバー時の色変化が統一されている
- [ ] 意図しない「ハードコードカラー」がないか（例: #ff0000 直書き）

## F. グリッド・整列

- [ ] コンテンツの左端が揃っている（不揃いがない）
- [ ] 複数カラムのレイアウトでカラム幅が統一されている
- [ ] アイコンとテキストの縦方向の揃いが統一（center/baseline）
- [ ] ラベルと入力欄の縦方向の揃いが統一
- [ ] ボタングループ内の揃いが統一

## G. 比率・スケールの遵守

- [ ] スペーシングに「5px」「11px」「22px」などトークン外の値が使われていない
- [ ] フォントサイズにスケール外の値が混入していない
- [ ] コンポーネントサイズに意図しない例外値がない

## H. インタラクション状態

- [ ] ボタンのホバー状態が全ボタンで統一
- [ ] ボタンの無効（disabled）状態のスタイルが統一
- [ ] ボタンの押下（active）状態が統一
- [ ] 入力欄のフォーカス状態が統一
- [ ] リンクのホバー・訪問済み状態が統一
- [ ] ローディング状態のスタイルが統一

## 監査スコアリング（オプション）

```
カテゴリ別スコア: 0（未確認）/ 1（問題あり）/ 2（許容範囲）/ 3（適合）

総スコア = 合計 ÷ (チェック数 × 3) × 100 %

80%以上: リリース可
60〜79%: マイナー修正推奨
60%未満: 修正必須
```
