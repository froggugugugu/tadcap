## 黄金比の特性

- φ = (1 + √5) / 2 ≈ **1.618**
- 特徴: `φ² = φ + 1` → 自己相似性がある
- 長辺と短辺の比が φ になる矩形が「黄金矩形」
- 余白と余白の比、フォントサイズの段差に自然なリズムが生まれる

## 白銀比の特性

- √2 ≈ **1.414**
- A4・B5等の紙サイズの縦横比
- 日本の伝統的な美意識との親和性が高い
- 段差が小さいため情報密度が高いUIでも圧迫感が出にくい

## 実用上のヒント

1. **比率を厳密に適用しすぎない**: 計算値が中途半端（例: 13.1px）になる場合は最寄りの整数に丸める
2. **8pxグリッドと併用する**: 比率スケールで出た値を8の倍数に近い値にスナップすると実装しやすい
3. **例外は記録する**: トークン外の値を使う場合は理由をコメントで残す
4. **画面サイズで基準値を変える**: モバイル base=14px / デスクトップ base=16px のようにbase値を変えて比率は維持する
