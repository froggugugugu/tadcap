# L0000 — <短い主題>

## 文脈(context)

どんな状況で観察されたか。ユーザーが何を求めていて、AI が何を提案したか。
1 段落で記述する。

## 観察された成功パターン(observation)

具体的に何が「うまくいった」のか。判断の起点(input)と、選んだ方針(decision)、
得られた結果(outcome)を 3 行で。

- **input**: <何を渡された / 何が起きていた>
- **decision**: <AI が選んだ方針>
- **outcome**: <どうなったか / なぜユーザーが評価したか>

## なぜこれが効くのか(why)

このパターンが効く理由を **1〜3 文**で。理由が説明できないものは
偶然の可能性が高い → confidence を下げるか pitfalls 寄りに分類し直す。

## 適用条件(applicability)

- どういうケースで参照すべきか(必須条件)
- どういうケースでは参照すべきでないか(除外条件)
- 関連する skill / agent / phase

## 反証 / 失敗事例(counter-examples)

このパターンが**通用しない**ケースがあれば記録する(ない場合は「なし」)。
反証が増えると confidence を下げる契機になる。
