## 1. ツールバー(FR-013、PRD §6・§10 #11)

### 1.1 並び

編集ツールのグループ(`#tool-toolbar`)を、細い区切り線で 2 つに分ける。

```
キャプチャ | 矢印 矩形 円 テキスト スタンプ ┆ モザイク スポットライト トリミング | 色 | 文字サイズ | 重ね順 | [スタンプの種類] (余白) 取り消し・やり直し | 機密らしい箇所を探す | コピー
             A    R    O   T        N           M        S              C
```

- **左の組(描く注釈)**: 矢印・矩形・円・テキスト・**スタンプ**。いずれも選択中の色を使う(色の選択がこの組に効く、と並びで分かる)。スタンプはテキストの直後(どちらも文字サイズに連動する)
- **右の組(画像そのものを変える)**: モザイク・**スポットライト**・**トリミング**。いずれも色を持たない。トリミングは画像の大きさを変える一番強い操作なので最後に置く
- 区切り線は `.tool-toolbar__divider`(幅 1px・高さ 20px・左右 3px・`--border-color`、`aria-hidden="true"`)。`toolbar.ts` の `TOOLS` に組の区切りを持たせ、`initToolbar()` が組の間に 1 本入れる
- モザイクの位置は 5 番目 → 6 番目に動く。キーは M のままなので操作は変わらない
- グループの `role="group"` / `aria-label="編集ツール"` は 1 つのまま(区切りは見た目だけ)

### 1.2 新しいアイコン

<!-- スポットライト(S): 外側を薄く塗り(モザイクと同じ 0.4〜0.45 の薄さ)、穴を輪郭で示す -->
<svg class="icon" viewBox="0 0 20 20" aria-hidden="true" focusable="false">
  <path d="M2 3.5h16v13H2ZM5.5 7v6h9V7Z" fill="currentColor" fill-rule="evenodd" opacity="0.4"/>

<!-- トリミング(C): かぎ形 2 つ -->

- 形の重なりの確認: スタンプ(丸 + 1)は円ツール(横長の楕円・中身なし)と、スポットライト(薄い塗りの中に穴)はモザイク(4 つの四角)・矩形(輪郭だけ)と見分けられた(`mock-toolbar.png` ④)

### 1.3 名前・ツールチップ・キー

キーの表は `ui/toolKeys.ts` の `TOOL_KEYS` 1 か所から読み、`aria-label`・`title`・`aria-keyshortcuts` を組み立てる(ARCH §9.1)。

| ツール | `aria-label` / `title` | `aria-keyshortcuts` | `event.code` |
| ------ | ---------------------- | ------------------- | ------------ |
| 矢印 | `矢印(A)` | `A` | `KeyA` |
| 矩形 | `矩形(R)` | `R` | `KeyR` |
| 円 | `円(O)` | `O` | `KeyO` |
| テキスト | `テキスト(T)` | `T` | `KeyT` |
| スタンプ | `スタンプ(N)` | `N` | `KeyN` |
| モザイク | `モザイク(M)` | `M` | `KeyM` |
| スポットライト | `スポットライト(S)` | `S` | `KeyS` |
| トリミング | `トリミング(C)` | `C` | `KeyC` |

- 表記は既存の静的ボタン(`取り消し(⌘Z)`)に合わせ、半角かっこ・空白なし・キーは大文字。ARCH §9.1 の例「矢印 (A)」は本書の形に読み替える
- `aria-label` が `矢印` → `矢印(A)` に変わる。既存 E2E の `getByRole("button", { name: "矢印" })` は部分一致なので通る。`exact: true` を使っている箇所があれば実装タスクで直す

### 1.4 窓の幅と折り返し

実測(`src/styles.css` のまま、Chromium):

| 状態 | ツールバーの必要な幅 |
| ---- | -------------------- |
| 今(5 ツール) | 760px |
| 8 ツール + 区切り | 867px |
| 8 ツール + スタンプの種類(§2.1) | 1042px |

今の既定の窓幅 800px には 8 ツールが収まらない。次のようにする(【要確認】#1 の推奨案 A):

- **既定の窓幅を 800 → 1080px に広げる**(`tauri.conf.json` の `width`。高さ 600 はそのまま)。スタンプの種類を出しても 1 段に収まる
- **窓を狭めたときは 2 段に折り返す**。何も隠さず、横スクロールもしない
  - `.toolbar`: `flex-wrap: wrap; height: auto; min-height: 40px; box-sizing: border-box; padding: 5px 8px; row-gap: 4px`(1 段のときの高さは今と同じ 40px、2 段で 74px)
  - 右のまとまり(取り消し・やり直し〜コピー)を `.toolbar__end`(`display: flex; gap: 4px; margin-left: auto`)で 1 つに包み、折り返しても右端にそろえる。今の `.toolbar__spacer` は要らなくなる
  - 段数が変わると Canvas の表示領域の高さが変わる。注釈のオーバーレイは既存の `ResizeObserver` で追従する(ARCH §5.2)

## 2. スタンプ(FR-001〜FR-004)

### 2.1 種類の切替(位置・出す条件)

- **スタンプツールを選んでいる間だけ出す**(`hidden` を切り替える)。種類は「これから置くスタンプ」の設定で、選択中のスタンプは変えない(FR-004: 取り消しの対象外なので、置いたものを変えると取り消せない変更になるため)。ほかのツールでは意味がないので隠す
- 位置: **重ね順のグループの後ろ(右のまとまりの手前の余白の先頭)**、前に区切り線 1 本。出し入れしても**既存のボタンが 1 つも動かない**(色・文字サイズ・重ね順の位置を手が覚えたまま使える)
- 作り: 文字サイズの 3 ボタン(`ui/fontSizePicker.ts`)と同じ。`<div class="tool-toolbar stamp-kind-picker" role="group" aria-label="スタンプの種類" data-preserve-selection>` に `.icon-button` を 5 つ、`aria-pressed` で選択中を示す。新設 `ui/stampKindPicker.ts`
- 既定は**番号**。選んだ種類はアプリを閉じるまで覚える(永続化しない。PRD §5)
- キーは割り当てない(PRD スコープ外)。Tab で届く

| 種類(`glyph`) | `aria-label` / `title` |
| -------------- | ---------------------- |
| `number` | `スタンプ 番号` |
| `check` | `スタンプ チェック` |
| `cross` | `スタンプ バツ` |
| `exclamation` | `スタンプ 注意` |
| `question` | `スタンプ 質問` |

(`文字サイズ 小` と同じ「対象 + 値」の形)

### 2.2 種類のアイコン

置かれるスタンプと同じ見え方にするため、**塗りの丸 + 地の色で抜いた記号**にする(ツールのアイコンは輪郭、種類は塗り、で役割も見分けられる)。押下中は丸がアクセント色になる。

```html
<!-- 共通: 丸 --> <circle cx="10" cy="10" r="7.5" fill="currentColor"/>
<!-- 記号の線の共通属性: fill="none" style="stroke: var(--surface-color)" stroke-width="1.7" stroke-linecap="round" stroke-linejoin="round" -->
番号:  <path d="M8.6 7.7 10.5 6.4V13.6"/>
チェック: <path d="M6.7 10.2 8.9 12.4 13.3 7.7"/>
バツ:  <path d="M7.4 7.4 12.6 12.6M12.6 7.4 7.4 12.6"/>
注意:  <path d="M10 6.2V10.9"/> + <circle cx="10" cy="13.7" r="1.05" style="fill: var(--surface-color)"/>
質問:  <path d="M7.9 8.1A2.1 2.1 0 1 1 10.9 10C10.3 10.3 10 10.7 10 11.3"/> + <circle cx="10" cy="13.8" r="1.05" style="fill: var(--surface-color)"/>
```

(`var(--surface-color)` で抜く書き方は既存の「最背面へ」のアイコンと同じ)

### 2.3 大きさ(決定論的な算出)

テキストの文字の大きさ `computeFontSizePx(size, w, h)`(`textLayout.ts:61-68`)を基準にする。新しい大きさの設定は増やさない(FR-001)。

| 定数(新設 `canvas/stampShape.ts`) | 値 | 内容 |
| ---------------------------------- | -- | ---- |
| `STAMP_DIAMETER_RATIO` | `1.2` | 直径 = `round(文字の大きさ × 1.2)` |
| `STAMP_MIN_DIAMETER` | `20` | 直径の下限(px) |
| `STAMP_RING_RATIO` | `0.07` | 白の縁の太さ = `max(2, round(直径 × 0.07))` |
| `STAMP_DIGIT_RATIO_1` | `0.58` | 1 桁の数字・「!」「?」の文字の大きさ = `round(直径 × 0.58)` |
| `STAMP_DIGIT_RATIO_2` | `0.48` | 2 桁の数字の文字の大きさ = `round(直径 × 0.48)`(FR-001 の 2 桁がはみ出さない) |
| `STAMP_STROKE_RATIO` | `0.11` | 「✓」「×」の線の太さ = 直径 × 0.11、端は丸 |

- 例(対角線は画像の実ピクセル): 2080 × 1204(対角 2403)の画像で 小 47 / 中 70 / 大 104px。2880 × 1800 の全画面で 中 98px
- 大きさの基準の対角線は `shapeStyleDiagonal()`(トリミング後は `styleBasis`、ARCH §15 #1)
- 記号の形(直径 D、中心からの位置):
  - ✓: (−0.22D, +0.01D) → (−0.06D, +0.17D) → (+0.23D, −0.15D) の折れ線
  - ×: 中心から ±0.165D の 2 本の対角線
  - 数字・!・?: `fillText`、`textAlign = "center"`、縦は `actualBoundingBoxAscent/Descent` で丸の中心にそろえる

### 2.4 見た目(描く順)

1. 影: 黒 35%、ぼかし D × 0.08、下へ D × 0.04(テキストと同じ比率。白い地で丸の輪郭を出す)
2. 白の円(直径 D)= 白の縁(暗い地で輪郭を出す)
3. 選択中の色の円(直径 D − 2 × 縁の太さ)
4. 記号: `700`(太字)、字体はテキストと同じ `system-ui, -apple-system, "Helvetica Neue", sans-serif`
   - 記号の色は**白**。ただし丸の色と白のコントラスト比が `2.5` 未満の明るい色(プリセットの橙 2.20・黄 1.51・緑 2.22 と、カラーピッカーで選んだ明るい色)では `#1a1a1a` にする(【要確認】#2 の推奨案 A。`stampGlyphColor(color)` を純粋関数にしてテストする)
   - プリセットで白になるのはピンク 2.94・赤 3.55・青 4.02

`mock-samples.png` の上段(案 A)と下段(常に白、案 B)を比べると、案 B の黄・橙・緑の数字は明るい地・暗い地のどちらでも読みにくい。

### 2.5 選択の表示

- 円の外側 4px(画面上)に、白の実線 1px + `rgba(0,0,0,.55)` の破線 `[4,3]` の輪(テキストの選択の枠と同じ部品)。ハンドルは出さない(FR-003)
- オーバーレイだけに描く(コピー・履歴に写らない)
- カーソル: スタンプツールでスタンプの上は `move`、空白は `crosshair`(既存の図形ツールと同じ)

## 3. スポットライト(FR-008〜FR-010)

### 3.1 暗さ

| 定数 | 値 | 内容 |
| ---- | -- | ---- |
| `SPOTLIGHT_SHADE`(`canvas/spotlight.ts`) | `rgba(0, 0, 0, 0.5)` | 穴の外側を 1 回だけ塗る色(【要確認】#3 の推奨案 A) |

- `mock-samples.png` 下段で黒 40% / 50% / 60% を比べた:
  - 明るい地: 40% は穴との差が弱い。50% で穴がはっきりし、周りの文字も読める。60% でも読める
  - 暗い地: 40% はほぼ区別できない。50% で穴の境目が分かる。60% だと穴がはっきり浮く
- ARCH の初期値 50% を採る(明るい画面の「うっすら読める」を優先)。実機確認(PRD §8.3)で暗い画面の見え方が弱ければ 60% にする

### 3.2 穴の見た目

- 選んでいない穴には枠を描かない(暗さの境目が輪郭になる。コピー結果と同じ見え方)
- 塗る領域は穴の和の外側。重なった穴の内側は暗くならない(`mock-light.png` 左上の 2 つの穴)
- 穴の外の注釈(矢印・スタンプ・テキスト)は明るいまま(PRD §10 #7)

### 3.3 選択の表示

- 既存の矩形と同じ四隅の丸ハンドル(半径 5px)+ 白の実線 1px と濃い破線 `[4,3]` の枠(円の外接矩形の枠と同じ部品)
- 掴める所: 枠の付近(矩形と同じ。内側では掴まない、ARCH §5.3)。カーソルは既存の矩形と同じ
- 穴を選んでいるとき、色の選択は何もしない(ツールの色だけ変わる、ARCH §5.3)。文字サイズも同じ

## 4. トリミング(FR-005〜FR-007)

### 4.1 範囲の表示(オーバーレイ。コピー・履歴に写らない)

| 部品 | 値 |
| ---- | -- |
| 範囲の外の暗さ `CROP_SHADE`(`canvas/tools/cropTool.ts`) | `rgba(0, 0, 0, 0.6)`。スポットライト(50%)より一段暗くし、「これから切り落とす所」と「焼き込まれる暗さ」を見分ける |
| 範囲の枠 | 白の実線 1.5px(内側)+ その外側に `rgba(0,0,0,.5)` の 1px |
| ハンドル | 四隅は**かぎ形**(長さ 16px・太さ 3px、白 + 1px の濃い縁)、四辺の中央は**棒**(長さ 16px・同じ太さ)。計 8 つ |
| 当たり判定 | 既存と同じ半径 10px(`HANDLE_HIT_RADIUS_CSS`)。範囲の内側は移動 |
| カーソル | 隅 `nwse-resize` / `nesw-resize`、辺 `ns-resize` / `ew-resize`、内側 `move`、外側 `crosshair` |

- かぎ形にする理由: 穴(丸ハンドル + 破線の枠)と同じ「矩形 + 外が暗い」見た目なので、ハンドルの形で区別する。辺の棒は片側だけ切り詰める操作のため(既存の矩形は四隅だけ)
- 寸法の表示は Canvas の上には出さず、帯に出す(§4.3)。画像の内容を隠さない

### 4.2 状態の流れ

| 状態 | 画面 |
| ---- | ---- |
| トリミングツールを選んだ(範囲なし) | 帯を出す(`ドラッグで残す範囲を囲んでください。`)。画像は暗くしない |
| ドラッグ中・範囲あり | 外側を暗く、枠とハンドル。帯に寸法、「やめる」「確定」 |
| 確定(Enter / 確定ボタン) | 画像を切り詰め、範囲を消す。トースト(info)`切り抜きました。⌘Z で戻せます。`。ツールはトリミングのまま(続けて切れる) |
| やめる(Esc / やめるボタン) | 範囲を消すだけ。トーストなし |
| ツールを外す・ほかのツール・新規キャプチャ・履歴の切替・自動マスキングの開始・範囲の指定中の ⌘Z / ⇧⌘Z | 範囲を捨てる(ARCH §7.1 C-6・§15 #4)。帯も消える(ツールを外したとき) |

- 帯は**ツールを選んだ時点で出す**。範囲を描き始めてから出すと、ドラッグ中に Canvas の位置が下へずれるため
- Enter・Esc は範囲がある間はトリミングが受け、選択の解除(`ui/selectionKeys.ts`)より先に処理する。範囲がないときの Esc は何もしない

### 4.3 帯(`ui/cropBar.ts`)

自動マスキングの結果バーと同じ作り・同じ位置(ツールバー直後の流し込み、`<div id="crop-bar" class="crop-bar" hidden>`)。CSS は `.mask-bar` と同じ値(高さ最小 36px・左右 12px / 8px・下罫線・0.9em・1 行)。ボタンは `.mask-bar__button` を共用する(実装で共通名に寄せてよい)。

| 部品 | 内容 |
| ---- | ---- |
| 状態の文(`<p class="crop-bar__status" role="status">`) | 範囲なし: `ドラッグで残す範囲を囲んでください。` / 範囲あり: `残す範囲` + 寸法 `1420 × 768`(半角、`×` の前後に半角空白、`font-variant-numeric: tabular-nums`)+ 補足(`--text-muted`)`枠やハンドルで調整できます` / 画像全体と同じ: 補足を `画像全体と同じ範囲です` |
| 「やめる」 | 枠付きのボタン + `<kbd>esc</kbd>`。範囲があるときだけ出す |
