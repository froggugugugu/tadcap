## 1. 実行ボタン(FR-001・FR-014)

### 1.1 位置

- ツールバー右側の**取り消し/やり直しのグループとコピーボタンの間**に置き、両側を区切り線で分ける:

  `キャプチャ | 編集ツール(矢印〜モザイク) | 色 | 文字サイズ | 重ね順 |(余白)| 取り消し・やり直し | [機密らしい箇所を探す] | コピー`

  実際には `index.html` の取り消し/やり直しのグループの後の区切り線と `#clipboard-copy-button` の間に、`#auto-mask-button` と区切り線を 1 本足す(区切り線は既存の 1 本を流用し、ボタンの後ろに 1 本足す)
- 理由: ①ツール切替(選んでドラッグする)と区切り線で離れ、「押すと処理が走る操作」だと分かる(ARCH §9.1・PRD §6)。②「貼る前の最後の確認 → コピー」の流れの順に並ぶ。③色・文字サイズのようにツールに付く設定の並びを崩さない
- トグル表示を持たない普通のボタン(`aria-pressed` を付けない)。`index.html` に直接書く静的なボタン(キャプチャ・コピーと同じ。§7.5)

## 2. 処理中の表示(FR-008)

- ボタンを押すと、ツールバーの直下に**結果バー**(§3)を出し、次を表示する:

## 3. 結果バー(FR-009・FR-011・FR-012)

### 3.1 配置と見た目

- ツールバー(`header.toolbar`)の直後、`.main-area` の前に流し込みで置く(`<div id="mask-bar" class="mask-bar" hidden>`)。権限の案内バナーと同じ位置づけ。Canvas の上に重ねないので、画像の上端付近の候補を隠さない
- 出すのは `scanning` と `review` の間だけ。`idle` で `hidden`
- 寸法: 高さ最小 36px、左右の余白 12px / 8px、下罫線 `--border-color`、背景 `--surface-color`、文字 0.9em
- 出入りでアニメーションはしない(Canvas の高さが 1 回変わり、印は `ResizeObserver` で追従する)

### 3.2 構成(左 → 右)

| 部品 | 内容 |
| ---- | ---- |
| 状態の文(`<p class="mask-bar__status" role="status">`) | 件数(§5)+ 補足文(`--text-muted`) |
| 「やめる」(`.mask-bar__button`) | 枠付きの控えめなボタン。右に `esc` のキー表示(`<kbd>`) |
| 「まとめてモザイク」(`.mask-bar__button--primary`) | 背景 `--mask-primary-bg`(`#1f1f1f`、トーストと同じ)・白文字。残りの候補が 0 件なら `disabled`(FR-011) |

- ボタンは既存の確認ダイアログのボタン(高さ 28px)より一段低い 26px(権限バナーのボタンと同じ)
- 「まとめてモザイク」の後: モザイクを 1 手で積み → 印とバーを消し → トースト(§5)
- 「やめる」・Esc: 印とバーを消す。トーストは出さない(何も変えていないため)
- キーボード: バーの出現でフォーカスは動かさない(Enter の誤操作で一括モザイクが走らないように)。Tab の順は「やめる」→「まとめてモザイク」→ 印(画像の上から下、同じ行は左から右)
- 0 件のとき: 状態の文を 0 件の文言(§5)にし、ボタンは「閉じる」1 つ(Esc でも閉じる)

## 4. 候補の印(FR-009・FR-010)

### 4.1 色のトークン(`src/styles.css` の `:root` に追加)

| CSS カスタムプロパティ | 値 | 用途 |
| ---------------------- | -- | ---- |
| `--mask-contact` | `#2563eb`(青) | ①連絡先 |
| `--mask-credential` | `#dc2626`(赤) | ②認証情報 |
| `--mask-identifier` | `#7c3aed`(紫) | ③個人・社内の識別子 |
| `--mask-financial` | `#047857`(緑) | ④金額・口座 |
| `--mask-halo-light` | `#ffffff` | 縁取りの 1 本目(暗いキャプチャで効く) |
| `--mask-halo-dark` | `rgb(0 0 0 / 75%)` | 縁取りの 2 本目(明るいキャプチャで効く) |
| `--mask-fill-alpha` | `14%` | 候補の領域の塗り(種類の色を混ぜる割合) |
| `--mask-line-width` | `2px` | 種類の色の線の太さ |
| `--mask-label-text` | `#ffffff` | ラベルの文字色 |
| `--mask-primary-bg` | `#1f1f1f` | 結果バーの「まとめてモザイク」の背景 |

4 色の確認値(WCAG のコントラスト比。計算は sRGB の相対輝度):

| 色 | 白(明るいキャプチャ)に対して | `#1e1e1e`(暗いキャプチャ)に対して | ラベル(白文字)の比 |
| -- | ---------------------------- | ---------------------------------- | -------------------- |
| `#2563eb` | 5.17 | 3.23 | 5.17 |
| `#dc2626` | 4.83 | 3.45 | 4.83 |
| `#7c3aed` | 5.70 | 2.93 | 5.70 |
| `#047857` | 5.48 | 3.04 | 5.48 |

- 線そのものは白地で 3:1 以上(非テキストの基準)。暗い地では 3:1 前後になるため、白の縁取りで補う(§4.2)。ラベルの白文字はすべて 4.5:1 以上
- 注釈のプリセット色(`#FF5C8A`・`#FF3B30`・`#FF9500`・`#FFCC00`・`#34C759`・`#007AFF`、`src/ui/colorPicker.ts`)より暗く彩度を抑えた値にし、塗り・縁取り・ラベルの組み合わせで注釈の線と区別する
- 色だけに頼らない: 種類は必ずラベルの文字でも示す(赤と緑の見分けにくさへの対策)

### 4.2 2 重の縁取り

印 1 つの見た目(内側から):

1. 領域の塗り: `color-mix(in srgb, var(--mask-color) var(--mask-fill-alpha), transparent)`
2. 種類の色の線: `border: var(--mask-line-width) solid var(--mask-color)`、角丸 2px
3. 白の縁取り 1px: `box-shadow: 0 0 0 1px var(--mask-halo-light)`
4. 黒の縁取り 1px: 同じ `box-shadow` の 2 つ目 `0 0 0 2px var(--mask-halo-dark)`

明るい地では黒の線が、暗い地・中間色の地(グラデーション)では白の線が輪郭になり、どちらの地でも色の線が浮く(モック画像で確認。§8)。

```css
.mask-mark {
  --mask-color: var(--mask-contact);
  position: absolute;
  box-sizing: border-box;
  padding: 0;
  border: var(--mask-line-width) solid var(--mask-color);
  border-radius: 2px;
  background-color: color-mix(in srgb, var(--mask-color) var(--mask-fill-alpha), transparent);
  box-shadow: 0 0 0 1px var(--mask-halo-light), 0 0 0 2px var(--mask-halo-dark);
  cursor: pointer;
}
.mask-mark--contact { --mask-color: var(--mask-contact); }
.mask-mark--credential { --mask-color: var(--mask-credential); }
.mask-mark--identifier { --mask-color: var(--mask-identifier); }
.mask-mark--financial { --mask-color: var(--mask-financial); }
```

### 4.3 ラベル

| 種類(`MaskKind`) | ラベル(`textContent`) | `aria-label` |
| ---------------- | ---------------------- | ------------ |
| `contact` | `連絡先` | `連絡先の候補` |
| `credential` | `認証情報` | `認証情報の候補` |
| `identifier` | `識別子` | `識別子の候補` |
| `financial` | `金額・口座` | `金額・口座の候補` |

- 置き方: 印の**右の外側**に、上下中央でそろえて 5px 離して置く(`.mask-mark__label`、10px / 行の高さ 14px / 太さ 600、左右の余白 4px、角丸 3px、背景は種類の色、§4.2 と同じ 2 重の縁取り)。候補の文字の上にラベルをかぶせない(確認したい文字が読めなくなるため。印の上端に置く案はモックで行の詰まった画面の文字を隠したので不採用)
- 右に置くと「画像の右端からはみ出す」または「別の印に重なる」ときは、左の外側に置く(`.mask-mark--label-start`)。左右どちらも重なるときは右に置く。判定は AM-T12 で純粋関数 `labelSide(rect, others, imageWidth, labelWidth): "end" | "start"` として書き、テストする
- ラベルは `pointer-events: none`(クリックは印本体で受ける)。重なり順は印の DOM 順のまま。ホバー・フォーカス中の印は `z-index: 1` で前に出す

### 4.4 外した印の見た目(FR-010)

| 部品 | 残っている候補(`aria-pressed="true"`) | 外した候補(`aria-pressed="false"`) |
| ---- | -------------------------------------- | ------------------------------------ |
| 線 | 実線 | **破線**(`border-style: dashed`) |
| 塗り | 種類の色 14% | なし(`transparent`) |
| 全体の不透明度 | 1 | 0.55 |
| ラベル | 種類の色の地に白文字 | 白の地に種類の色の文字(地と文字を反転) |
| ツールチップ(`title`) | `クリックで外す` | `クリックで戻す` |

- 線の形(実線/破線)・塗りの有無・ラベルの反転の 3 つで区別し、色の見分けに頼らない

### 4.5 操作とアクセシビリティ

- 印は 1 件ずつ `<button type="button" class="mask-mark mask-mark--<種類>">`。位置は `left/top/width/height` の %(ARCH §9.1)
- `aria-pressed` は「**モザイクの対象に含めるか**」: 初期値 `true`、外すと `false`。読み上げは「連絡先の候補、切り替えボタン、オン」
- クリック・Space・Enter で外す/戻す(`toggleCandidate(id)`)
- ホバー: 塗りを 28% に濃くする。フォーカス(`:focus-visible`): `outline: 2px solid var(--accent-color); outline-offset: 3px`(既存のフォーカスリングと同じ色)
- 確認中は `.mask-overlay` がポインタを受け、印以外のクリックは何もしない(ARCH §9.1)
