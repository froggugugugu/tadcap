# ブレスト: 機密情報の自動マスキング

- 作成日: 2026-10-09
- 起点: 差別化の看板機能として、人間が「欲しい」と決定(2026-10-09)。後続の柱は手順書モード(別ブレスト)
- 質問: 4 ラウンド・15 問(回答はすべて人間)

## 1. 要求の核(一文)

キャプチャした画像の文字を **Mac の中だけで** 読み取り、機密らしい箇所を候補として示し、**ボタン 1 つでまとめてモザイクにできる**ようにする。チャットに貼る前の隠し忘れを減らすため。

**コンセプト(人間の言葉)**: 隠し忘れの「最後の締め」。貼る前にボタンを 1 回押すだけで、気づいていなかった機密に印が付き、安心して貼れる。
**位置づけ**: 利用者が**意識して押す追加の便利機能**。自動で守る仕組みではない(2026-10-09 人間が確認)。

## 2. 前提の棚卸し

### 人間が明示した前提(回答)

| 項目 | 決定 |
| ---- | ---- |
| 検出対象 | 4 種すべて: ①連絡先(メール・電話番号) ②認証情報(API キー・トークン・パスワードらしき文字列・URL のクエリ) ③個人・社内の識別子(人名・社員番号・顧客番号) ④金額・口座(カード番号・口座番号・金額) |

| 精度の方針 | **見逃しを避ける**(多めに出し、人が外す) |

| 日本語の固有名詞 | **最初の版に入れるが目標は低め**。精度は後の版で高める |

| 隠し方 | **今のモザイクツールと同じモザイク**(当初「今より粗い」と回答したが変更。手で追加するモザイクと 2 種類になるのを避けるため。2026-10-09) |
| やらない | 外部通信・クラウド AI / 読み取った文字や検出結果の保存 / 顔・アイコンなど画像としての検出 / 「すべて隠しました」という保証の表示 |

### 暗黙の前提(要確認)

- 【前提】文字の読み取りは macOS 標準の Vision(`VNRecognizeTextRequest`)を使う。日本語の認識は macOS 13 以降で使え、対応 OS(14 以降)を満たす。追加の依存やモデルの同梱は不要
- 【前提】メール・電話・カード番号・URL・API キーなど**形が決まっているもの**は、正規表現とチェックディジット(カード番号の Luhn)で判定できる
- 【前提】**人名・住所・会社名など形が決まっていないもの**は、正規表現では拾えない。macOS の固有表現抽出(`NLTagger` の nameType)の日本語の精度、または辞書や手がかり語(「様」「さん」「株式会社」「〒」など)による判定が必要になる。見逃しを避ける方針と最も衝突しやすい部分
- 【前提】候補の「一括モザイク」は、今のモザイクツールと同じく元画像に焼き込み、取り消し(⌘Z)の 1 手として扱う
- 【前提】**モザイクの粗さは、文字を復元されない強さが必要**。今のブロックサイズは画像幅の約 0.9%(フル HD で約 18px)。短い英数字のモザイクは、復元を試みる手法の対象になりうる。機密マスキングでは塗りつぶし、またはもっと粗いブロックが妥当かもしれない
- 【前提】読み取りは Rust 側(Vision を objc2 経由で呼ぶ)か、Swift の小さな補助プロセスで行う。Tauri の webview からは直接呼べない。読み取った文字はメモリ上でだけ扱い、ログにも出さない
- 【前提】検出率を測る評価用の画像は**架空のデータだけ**で作り、リポジトリに入れてよい(実在の個人情報・社内情報は使わない)

## 3. ステークホルダーと利害

| 誰 | 期待 | 恐れ |
| -- | ---- | ---- |
| 利用者(社内でキャプチャを貼る人) | 貼る前に隠し忘れに気づける。手作業のモザイクが減る | 候補が多すぎて邪魔。待たされる。外し忘れて必要な所まで隠す |
| 情報システム部門・セキュリティ担当 | 通信しない・残さないことを説明できる。漏えいの事故が減る | 「自動で隠れる」と誤解され、確認を怠る人が出る。読み取った文字がどこかに残る |
| 受け取る側(チャット・資料の読み手) | 必要な情報は読める | 隠しすぎで内容がわからない |
| 開発者(人間 + AI) | 差別化の看板になる | 日本語の人名・住所の精度が上がらず、検出率の目標に届かない |

## 4. やる/やらない境界の候補

| | Minimum | Standard(推奨) | Ambitious |
| - | ------- | ---------------- | --------- |
| 検出対象 | 形が決まっているもの: メール・電話・URL クエリ・API キー/トークン・カード番号・口座番号・金額 | Minimum + 日本語の人名・会社名・住所を手がかり語と固有表現抽出で検出 | Standard + 利用者が形式・語を登録 / 設定ファイルで配る |
| 操作 | ボタン → 候補表示 → 一括モザイク・個別に外す | 同左 + 種類ごとの表示/非表示、ショートカット | 同左 + 撮った直後の自動実行を設定で選べる |
| 隠し方 | 今のモザイク | 機密用に強い隠し方(塗りつぶし or 粗いブロック) | 隠し方を選べる |
| 評価 | 形が決まっているものの検出率 | 全種類の検出率(評価用画像セット) | 同左 + 実利用での体感の記録 |
| 規模感 | 小〜中 | 中〜大(日本語の固有名詞が山場) | 大 |

回答との整合: 「日本語も最初から」は Standard 以上。「独自の形式は固定だけ」「ボタンを押した時だけ」は Standard の範囲。
