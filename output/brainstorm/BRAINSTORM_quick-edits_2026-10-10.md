# ブレスト: 小さな編集機能(番号スタンプ・トリミング・スポットライト・縮めてコピー)

- 作成日: 2026-10-10
- 起点: 職場で欲しい機能の候補から、人間が 1〜5 を採用(2026-10-10)。このブレストは 1・2・3・5 を扱い、4(手順書モード)は番号スタンプを土台に別ブレストで行う
- 質問: 3 ラウンド・10 問(回答はすべて人間)

## 1. 要求の核(一文)

手順や指摘を伝える画像を、**他のアプリを使わずに Tadcap だけで**作って貼れるようにする。そのために、番号・記号のスタンプ、撮った後の切り抜き、一部の強調、貼り先向けの縮小を、「撮る → 描き込む → 貼るを最短で」「何も残さない」を崩さずに足す。

## 2. 前提の棚卸し

### 人間が明示した前提(回答)

| 機能 | 決定 |
| ---- | ---- |
| 番号スタンプ | 選択中の色の丸に白い数字。クリックするたびに連番(画像ごとに 1 から)。消すと以降の番号を詰める。後から移動・削除できる |
| 番号スタンプの大きさ | 既存の文字サイズ(小・中・大)に連動。新しい設定は増やさない |
| 記号のスタンプ | **今回の範囲に含める**(✓・NG など。番号と同じ仕組み) |
| トリミング | ツールで範囲を囲み、外側を暗く表示 → Enter/ボタンで確定、Esc でやめる。⌘Z で戻せる |
| トリミングと描いた物 | 残して位置を合わせる(座標をずらす)。範囲外にはみ出した部分は切れる。⌘Z で全部戻る |
| スポットライト | 囲んだ範囲以外を暗くする。複数の穴を開けられる。後から移動・リサイズ・削除できる |
| スポットライトの暗さ | 固定(中くらい。周りの文字がうっすら読める程度)。設定は増やさない |
| 縮めてコピー | 設定画面で「⌘C は等倍(Retina なら 1/2)でコピー」をオンにできる。普段の操作は増やさない |
| キーボードショートカット | **今回の範囲に含める**(既存ツールも含め、ツールを 1 キーで切り替え) |
| 成功条件 | 番号付きの手順画像を、Tadcap だけで作って貼れる(他のアプリを使わない)。実機の操作で確かめる |
| やらない | 回転・反転・自由な形の切り抜き(トリミングは矩形のみ)/ ファイルへの保存・画質や形式の細かい設定(縮めてコピーは等倍のオン/オフのみ) |

### 暗黙の前提(要確認)

- 【前提】スタンプとスポットライトは、既存の矢印・枠・円と同じ「後から選び直して調整できる注釈」として扱う(1 画像 50 個の上限、重ね順、取り消し、履歴への退避に含める)
- 【前提】スポットライトはコピー時に画像に焼き込まれる(貼った先でも暗いまま)。表示だけの効果ではない
- 【前提】トリミングは元画像(ベース)を切り詰める操作で、取り消し 1 手。履歴のサムネイルも切り詰め後になる
- 【前提】トリミング中・スポットライト配置中の自動マスキングは、既存の確認モードと同じく競合しないよう止める。トリミングの確定で自動マスキングの候補は破棄する(画像が変わるため)
- 【前提】「縮めてコピー」は、撮った直後の自動コピーにも同じ設定を適用する(⌘C と結果を揃える)
- 【前提】キーボードショートカットは、テキスト入力中・設定画面の記録中には効かない。既存の ⌘ 付きのキー(⌘C・⌘Z・⇧⌘F など)や自動マスキングの ⌘⇧M と重ならない、修飾キーなしの 1 文字
- 【前提】依存パッケージは追加しない(既存の Canvas 描画で足りる)

## 3. ステークホルダーと利害

| 誰 | 期待 | 恐れ |
| -- | ---- | ---- |
| 利用者(手順・指摘を伝える人) | 番号を打つ・余計な所を切る・1 か所を目立たせるが速い。貼った先で大きすぎない | ツールが増えてツールバーが混む。どのツールか迷う |
| 受け取る人 | 手順の順番がすぐ分かる。見るべき所が一目で分かる | スポットライトで周りが読めず文脈が失われる |
| 開発者(人間 + AI) | 既存の注釈の仕組みに乗せて小さく作れる | トリミングで座標を持つ全機能(注釈・取り消し・履歴・自動マスキング)に影響が出る |

## 4. やる/やらない境界の候補

| | Minimum | Standard(回答に沿う) | Ambitious |
| - | ------- | -------------------- | --------- |
| スタンプ | 番号のみ | 番号 + 記号(✓・× など数種) | 記号を利用者が追加できる |
| トリミング | 描く前だけ・矩形 | 描いた後も可(座標を合わせる)・矩形 | 縦横比の固定・数値指定 |
| スポットライト | 1 か所・固定の暗さ | 複数の穴・固定の暗さ・後から調整 | 暗さ・ぼかしを選べる |
| 縮めてコピー | 設定のオン/オフ(等倍) | 同左 + 撮った直後の自動コピーにも適用 | 最大幅の指定・形式の選択 |
| ショートカット | なし | 全ツールに修飾キーなしの 1 文字 | 利用者が割り当てを変えられる |
| 規模感 | 小 | 中(トリミングの影響範囲が山場) | 中〜大 |

## 5. 未解決の質問リスト(★ = `/prd` の前に解消したい)

1. 記号のスタンプの種類と数(例: ✓・×・!・? の 4 種か、もっと絞るか)。色は選択中の色か、記号ごとの固定色か
2. ツールのキー割り当て(例: 矢印 A・枠 R・円 O・テキスト T・モザイク M・番号 N・スポットライト S・トリミング C)。既存のキーとの衝突の確認
3. トリミングの確定後に、範囲外へ完全に出た注釈(例: 範囲外の矢印)を消すか残すか(見えないまま残すと 50 個の上限を食う)
4. スポットライトの穴の形(矩形のみか、角丸・楕円も選べるか)
5. 縮めてコピーで、もともと等倍(Retina でない画面)の画像はそのまま。外部ディスプレイと Retina が混在したときの基準(撮った画面の倍率)
6. ツールバーのボタンの並び(スタンプ・スポットライト・トリミングの位置)。UI 仕様で決める

★ 付きは無い(いずれも PRD の【要確認】か UI 仕様で決められる粒度)。
