## 調整した内容と理由

| 対象 | 変更 | 理由(評価で見つかった読み取りの形) |
| ---- | ---- | ---- |
| URL のクエリ(`credential.rs`) | 空白 1 つの後に `=`・`?` を含む塊が続けば URL の続きとする | クエリやパスの途中に読み取りで空白が入る |
| 同上 | `?` が無くパスに `=` があれば、最初の `=` の前のキーとその直前の 1 文字からをクエリとする | `?` が数字に誤読される |
| 同上 | スキームの無いパス(語頭の `/` から始まり `?` と `=` を含む)も URL とみなす | ログの `GET /export?…` |
| 接頭辞付きトークン・長いランダム列(`credential.rs`) | 空白 1 つずつで続く塊を何か所でもつなぐ。続きの条件に「大文字・小文字の切り替わり 2 回以上」を足す | 本体の途中に空白が 2 か所以上入る、英字だけの短い断片に分かれる |
| 同上 | 塊の末尾の `]`・`\|` 1 文字を含める | 末尾の 1 文字が全角の `]` に誤読される(元の文字は `l`・`I` などと推定) |
| 手がかり語の値(`credential.rs`) | 値の後に空白 1 つで、英数字と英字以外を含み `:`・`=` を含まない塊が続けば値に含める | 値の途中に空白が入る |
| カード番号(`financial.rs`) | 横に並ぶ数字だけの観測(隙間は 1 文字の幅の 2 倍以内・小さな重なりも可)を最大 4 つつなぎ、カードの形なら各観測を返す | 1 つの番号が 2〜3 個の観測に分かれる |
| 口座番号(`financial.rs`) | ラベルの右隣・直下の値で、数字の前の 1〜3 文字 + 空白(誤読された預金の種類)を許す | 「当座」が別の字や記号に読まれる |
| メール(`contact.rs`) | ドメインの途中の語に空白 1 つ(続きが小文字・数字)を許す。最後の `.` が落ちた形は `com`/`net`/`org`/`jp` で終わるときだけ認める | 語の途中の空白、`.jp` の点の脱落 |
| 余白(`geometry.rs`) | 係数 0.2 → **0.25** | 下の比較を参照 |
| 言語補正(`ocr.rs`) | **オフのまま** | 下の比較を参照 |
