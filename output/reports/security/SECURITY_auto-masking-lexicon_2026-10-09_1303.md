ローマ字の変換規則(外務省「ヘボン式ローマ字綴方表」の規則。表は取得・複製していない):

- 基本: し=shi / ち=chi / つ=tsu / ふ=fu / じ・ぢ=ji / ず・づ=zu / を=o / 拗音(しゃ=sha 等)
- 促音: 次の子音を重ねる(はっとり → hattori)。ち・ちゃ行の前は t
- 撥音: b・m・p の前は m(なんば → namba)。表記揺れとして n も生成(nanba)

- 語の境目をまたぐ母音は長音にしない(元データで `いの|うえ` → inoue、`せの|お` → senoo)
