### WARNING(対応推奨)

- [ ] **一時キャプチャファイルの自動削除が無い(プライバシー)** スクリーンショット(機微情報を含みうる)は `$TMPDIR/tadcap-captures/*.png` に生成されるが(`src-tauri/src/capture/tempfile.rs`)、アプリ内に本番経路での削除処理が見当たらない。`remove_file` の使用箇所は `src-tauri/src/capture/screencapture.rs:65,72` のテストコードのみで、`capture/mod.rs`・`commands.rs` にも履歴 eviction 時やアプリ終了時のクリーンアップは無い。**根拠**: 個人情報保護法上の安全管理措置・利用目的達成後の適切な廃棄の考え方、GDPR適用時のストレージ制限原則(データ最小化)。**推奨対応**: (a) クリップボードコピー成功時・履歴からの eviction 時・アプリ終了時のいずれかで一時ファイルを削除する処理を追加する、または (b) 削除しない設計を維持するなら保持期間ポリシー(OS一時ディレクトリの自動クリーンアップに依存する旨)を公開前にドキュメント化・利用者への説明に含める。

- [ ] **Rust依存(513パッケージ)のライセンスを機械的に未検証** `src-tauri/Cargo.lock` は513パッケージを解決しているが、Cargo.lock(v4)自体に `license` フィールドが無く、`cargo-license`/`cargo-deny` も未導入のため全件の機械確認ができていない。直接依存(`tauri`, `tauri-plugin-*`, `serde`, `serde_json`, `thiserror`, `arboard`)は一般に知られている範囲ではMIT/Apache-2.0デュアルライセンスの著名クレートだが、推移的依存まで含めた確定的な確認ではない。**根拠**: GPL/AGPL系ライセンスが混入した場合の派生物ソース公開義務(コピーレフト)。**推奨対応**: 公開前に `cargo install cargo-license && cargo license` または `cargo-deny check licenses`(許可リスト方式)をCIに追加し、GPL/AGPL系が無いことを機械的に確認する。

- [ ] **配布物向けの依存ライセンス帰属表示(NOTICE)が無い** ルートに本プロジェクト自身の `LICENSE`(MIT)はあるが、npm/Rust依存(MIT/Apache-2.0/ISC/BSD-3-Clause等)の著作権表示・ライセンス全文をまとめた `THIRD-PARTY-NOTICES` 等のファイルは存在しない。**根拠**: MITの「上記の著作権表示および本許諾表示を、ソフトウェアのすべての複製または重要な部分に記載する」義務、Apache-2.0 §4(帰属表示・NOTICE保持義務)。**推奨対応**: `.dmg`/`.app` として一般配布する前に、依存パッケージのライセンス集約ファイルを生成し(例: `npx license-checker --csv` / `cargo about`)、リポジトリまたはアプリ内(About画面等)に同梱する。

- [ ] **macOS画面収録権限の使用目的説明キーの要否が未確認** ビルド済み `Info.plist`(`src-tauri/target/release/bundle/macos/Tadcap.app/Contents/Info.plist`)には `NSCameraUsageDescription` 等に相当する画面収録用の使用目的文字列キーは含まれていない。一般に画面収録(TCC `Privacy_ScreenCapture`)はカメラ/マイクと異なりInfo.plistの使用目的文字列を要求せず、システム設定にはアプリ名のみが表示されると理解しているが、本レビューでは Apple 公式ドキュメントへの一次情報確認は行っていない(要調査)。**推奨対応**: 公開前に Apple Developer 公式ドキュメントで最新の要否を確認する。

### INFO(参考情報)

- [ ] **外部デザイン指針の取り込み方針は適切** `output/reports/ui/UI_REVIEW_T19.md` 冒頭に「外部の一般的なUIデザイン監査観点」「抑えたエディトリアル系ミニマルUIの方向性」を「いずれも一般的な設計指針として適用し、本ドキュメント・コード中に固有の製品名・リポジトリ名は記載しない」と明記されており、MITライセンス文章やコードの逐語的な取り込みは確認されなかった。**補足**: 現状は帰属表示義務が生じる取り込みは無いと判断できるが、今後も具体的な製品名・コード片を引用しない方針の継続を推奨する。

- [ ] **インラインSVGアイコンは自作の単純図形** `src/ui/toolbar.ts`(矢印・モザイク)、`index.html`(カメラ・クリップボード)のアイコンは単純な線・矩形・円で構成され、Feather Icons / Material Icons / Font Awesome / Heroicons / SF Symbols 等の既知アイコンセット名や出典コメントはコード中に見当たらない(リポジトリ全体をgrepし0件)。**補足**: 単純な幾何学的UIアイコンは一般に著作権保護になじみにくく現時点でリスクは低いが、断定はできない。今後アイコンを追加する際も既存アイコンセットのグリフをトレースしないことを徹底する。

- [ ] **外部への通信・送信は確認されず** `src`・`src-tauri/src` を `fetch`/`XMLHttpRequest`/`reqwest`/`hyper`/`WebSocket` 等でgrepしたが該当箇所は0件。`tauri.conf.json` の CSP (`connect-src: 'self' ipc: http://ipc.localhost`) も外部接続を許可していない。スクリーンショットやユーザーデータが外部サーバーへ送信される経路は現状確認できない。

- [ ] **セッション内履歴はメモリのみ・非永続** `src/history/historyStore.ts` は画像/サムネイルを `ObjectURL`(Blob)として保持し、ディスクや `localStorage`/`IndexedDB` への永続化は無い(grep結果0件)。上限50件超過時・アプリ終了時に破棄される設計であり、プライバシー上のリスクは相対的に低い。

- [ ] **Cargo.lockにGTK/WebKitGTK系クレートが含まれるが本ビルドには不使用** `atk`, `cairo-rs`, `gdk`, `glib`, `gtk`, `javascriptcore-rs`, `libappindicator`, `pango`, `soup3`, `webkit2gtk` 等がロックファイルに存在するが、これはTauri/wryの全プラットフォーム依存解決による副産物であり、本プロジェクトはmacOS専用(`tauri.conf.json` の `bundle.targets: ["app","dmg"]`、コード側 `#[cfg(target_os = "macos")]`)のためLinux向けの実体はコンパイル・同梱されない。**補足**: 将来Linux対応する場合は、GTK/WebKitGTK(LGPL系)の動的リンク条件を改めて確認する必要がある。

- [ ] **devDependency `lightningcss` はMPL-2.0** `vite` の内部依存として `node_modules/lightningcss`(および `lightningcss-darwin-arm64`)がMPL-2.0。ビルド時のみ使用されアプリバイナリには同梱されないため配布義務は発生しないと考えられるが、ファイルレベルコピーレフトである点は認識しておく。

- [ ] **未文書化のApple private URLスキームへの依存** `src-tauri/src/commands.rs:218-224` で `x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture` という非公式・未文書化のURLスキームを使用しており、コード内コメントで【仮定】として明記済み(将来のmacOSバージョンで変更されうることを許容)。法的リスクというより技術的な将来メンテナンスリスク。

- [ ] **Apple商標の使用は記述的(nominative)使用のみ** README.md の「macOS 14 (Sonoma) 以降」等はシステム要件の記述であり、Apple社の推奨・提携を示唆する記載やロゴ使用は見当たらない。問題なし。

## データ保護サマリー
- 個人情報に該当しうるフィールド: スクリーンショット画像そのもの(`CaptureResult.sourcePath`、クリップボード書込用RGBA8バイト列)。ユーザーが撮影する画面内容次第で個人情報・機微情報を含みうる。
- 保存方式: (1) OS一時ディレクトリ `$TMPDIR/tadcap-captures/*.png`(削除処理なし、WARNING参照)。(2) フロントエンド側 `historyStore` のメモリ内 `ObjectURL`(上限50件、非永続、アプリ終了で破棄)。
- 暗号化: なし(該当なし)。ローカル一時ファイルは平文PNG。
- 第三者提供・外部送信: 確認されず(ネットワーク通信コード0件、CSPも外部接続不許可)。

## 推奨アクション
1. 一時キャプチャファイル(`$TMPDIR/tadcap-captures/`)の削除方針を決める(自動削除実装 or 保持ポリシーの明文化)。機微情報を含みうる画像がOS任せで無期限に残る点は公開前に対応または説明を用意する。
2. 公開(初回リリース)前に `cargo-deny`(または `cargo-license`)をCIに追加し、Cargo.lock全513パッケージのライセンスをGPL/AGPL不在の観点で機械的に確認する。
3. npm/Rust依存のライセンス全文・著作権表示をまとめた `THIRD-PARTY-NOTICES` 相当のファイルを用意し、配布物(dmg)またはリポジトリに同梱する。
4. macOS画面収録権限に関するInfo.plist使用目的文字列の要否をApple公式ドキュメントで一次確認する。
5. `x-apple.systempreferences:...` の未文書化URLスキーム依存について、将来のmacOSアップデートでの動作確認を継続監視項目としてPROGRESS.md等に残す(既に【仮定】明記済みのため継続確認のみ)。
