# Tadcap 要件定義（ドラフト）

## 目的
キャプチャ起点の作業（バグ報告、手順書、レビュー指摘）を最短操作で完了させる。

## スコープ
- 対象OS: macOS 14+
- 主役: キャプチャ / 脇役: 注釈

## 機能要件（MVP候補 — 要確定）
| ID | 機能 | 優先度 |
|----|------|--------|
| F-01 | 範囲指定キャプチャ | Must |
| F-02 | ウィンドウキャプチャ | Must |
| F-03 | 全画面キャプチャ | Should |
| F-04 | グローバルショートカット | Must |
| F-05 | クリップボードへコピー | Must |
| F-06 | 注釈（矢印・枠・テキスト） | Must |
| F-07 | モザイク / ぼかし | Should |
| F-08 | メニューバー常駐 | Should |
| F-09 | 履歴一覧 | Could |

## 非機能要件
- ショートカット押下からキャプチャUI表示まで: 目標値を決める
- 画面収録権限が未許可の場合の案内フロー

## 未決事項
- MVPの範囲
- 保存先・ファイル形式（PNG固定か）
- キャプチャ実装方式（ScreenCaptureKit / screencapture CLI）
