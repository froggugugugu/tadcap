# Tadcap 要件定義（ドラフト）

## 目的
キャプチャ起点の作業（バグ報告、手順書、レビュー指摘）を最短操作で完了させる。
「撮る → 矢印・モザイクで印をつける → クリップボードに載せて貼る」をひと続きの最短操作で行える、ミニマルな OSS ツールを目指す。

## スコープ
- 対象OS: macOS 14+（macOS 専用。他OS対応はしない）
- 主役: キャプチャ / 脇役: 注釈
- 主要な出力先: クリップボード（チャット・ドキュメントツール・エディタ等へ即貼り付け）

## 技術スタック
| 層 | 採用 | 備考 |
|----|------|------|
| フレームワーク | Tauri v2 | |
| フロントエンド | Vanilla HTML / CSS / TypeScript | React・Vue 等の重量級フレームワークは使わない |
| 画像編集 | HTML5 `<canvas>` | 注釈・モザイクはすべて Canvas 上で処理 |
| バックエンド | Rust | システムコマンド実行、クリップボードのフォールバック |
| クリップボード | `@tauri-apps/plugin-clipboard-manager` | 画像書き込みに難があれば Rust コマンドで代替 |

## 機能要件
| ID | 機能 | 優先度 | MVP |
|----|------|--------|-----|
| F-01 | 範囲指定キャプチャ | Must | ✓ |
| F-02 | ウィンドウキャプチャ | Must | ✓（`screencapture -i` のスペースキー切替で対応） |
| F-03 | 全画面キャプチャ | Should | |
| F-04 | グローバルショートカット | Must | |
| F-05 | クリップボードへコピー | Must | ✓ |
| F-06a | 注釈: 矢印 | Must | ✓ |
| F-06b | 注釈: 枠・テキスト | Should | |
| F-07 | モザイク / ぼかし | Must | ✓ |
| F-08 | メニューバー常駐 | Should | |
| F-09 | 履歴一覧（セッション内） | Must | ✓ |

### F-01 / F-02 キャプチャ
- Rust 側から macOS 標準の対話型キャプチャを起動する: `screencapture -i <出力パス>`
- 出力パスは一時ディレクトリ配下にキャプチャごとに一意なファイル名で作成する（履歴で過去画像を保持するため、固定パス `/tmp/captured_shot.png` の上書きはしない）
- ユーザーが Esc でキャンセルした場合（ファイル未生成）はエラー扱いにせず、何もしない
- 撮影後、画像をフロントエンドへ渡し Canvas に読み込む
- 実装は `src-tauri/src/capture/` に閉じ込める

### F-06a 矢印ツール
- 始点から終点へのドラッグで、くっきりした矢印を描画する
- 色: 視認性の高い鮮やかなピンク `#FF5C8A`（既定色）

### F-07 モザイク / ぼかしツール
- 矩形をドラッグし、その領域をピクセル化（またはぼかし）して機微情報を隠す
- Canvas のピクセルに焼き込む（CSS フィルタのみの見た目変更は不可。コピー結果に反映されないため）

### ツール切替
- 矢印 / モザイクをシンプルなトグルで切り替える

### F-05 クリップボードへコピー
- 目立つ位置に「クリップボードにコピー」ボタンを置く
- ショートカット: `Cmd + C`
- Canvas 上のマークアップ済み最終画像（PNG）を macOS のクリップボードへ直接書き込む

### F-09 履歴一覧
- そのセッション中に撮影・編集したスクリーンショットをサイドバー（リスト）に表示する
- 項目クリックでその画像を Canvas に再読み込みする
- 永続化はしない（アプリ終了で破棄）

## 非機能要件
- ショートカット押下からキャプチャUI表示まで: 目標値を決める
- 画面収録権限が未許可の場合の案内フロー
- 軽量に保つ（依存を最小限に）

## 未決事項
- 保存先・ファイル形式（ファイル保存機能を持つか。持つなら PNG 固定か）
- キャプチャ実装方式の将来移行（MVP は screencapture CLI。ScreenCaptureKit へ移行するか）
- 履歴の再読み込み時、元画像を読み込むか編集後画像を読み込むか（注釈をやり直せる設計にするか）
- モザイクとぼかしのどちらを既定にするか（両方持つか）
